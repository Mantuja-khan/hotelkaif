# ARCOVA Architecture Website

## Goal
Create a polished, responsive multi-page architecture website that closely follows the supplied reference: dark charcoal and warm ivory surfaces, muted gold accents, elegant editorial serif headings, compact sans-serif details, premium architectural photography, and restrained motion.

## Pages
- **Home:** Full-width residential hero, primary call to action, statistics panel, featured projects, service categories, five-step process, insights, and contact-led footer.
- **About:** Studio story, design philosophy, experience figures, values, and team/studio imagery.
- **Services:** Architecture, residential construction, commercial builds, interiors, and project management, each with clear scope and process.
- **Projects:** Refined portfolio grid with project names and locations, plus focused project presentation sections.
- **Insights:** Editorial article grid using architecture, materials, interiors, and sustainability themes.
- **Contact:** Project enquiry form, contact information, address, and social links.

## Visual Direction
- Reproduce the reference’s visual hierarchy, type scale, spacing rhythm, thin rules, dark/light section alternation, gold line icons, sharp photography crops, and compact buttons.
- Use an editorial high-contrast serif for major headings and a clean geometric sans serif for navigation, labels, and body text.
- Preserve the home composition closely: overlay navigation and copy on the hero image, overlapping statistics strip, asymmetric project gallery, dark services band, horizontal process timeline, article cards, and substantial dark footer.
- Generate a cohesive set of original luxury residential, commercial, interior, and material images matching the reference’s photographic mood rather than embedding the uploaded screenshot.
- Add subtle image reveals, link transitions, and reduced-motion support without distracting effects.

## Navigation and Interaction
- Shared desktop navigation and a compact mobile menu connect all six pages.
- All calls to action link to the relevant project, services, insights, or contact page.
- The contact form includes clear fields, validation, and an on-page confirmation state; submission remains presentation-only unless persistent delivery is requested later.
- Layouts adapt for mobile, tablet, and desktop while retaining the reference’s hierarchy.

## Content and Quality
- Use the visible ARCOVA name, labels, project names, statistics, and wording from the supplied reference where readable; extend secondary pages with consistent editorial copy.
- Give every page a unique title, description, and social-sharing metadata.
- Use semantic headings, accessible labels, keyboard-friendly controls, descriptive image text, and optimized image loading.
- Verify all pages, navigation, forms, imagery, and responsive layouts in the running preview.

## Technical Notes
- Build with the existing TanStack Start structure and Tailwind design tokens.
- Define the complete palette, typography, borders, and shadows centrally so all pages remain visually consistent.
- Keep shared navigation, footer, buttons, project cards, and editorial cards reusable while allowing each page its own composition.
